# split out (21 Aug 2026) because a fork that wants to reproduce our numbers

#     pip install -r requirements-media.txt    # plus browsers and screen capture

# Every import below is guarded in the code, and the step that needs it announces
# its own absence rather than dying. Same pinning rule as requirements.txt: exact
# versions, measured from venv/ on 21 Aug 2026 under CPython 3.14.5.
