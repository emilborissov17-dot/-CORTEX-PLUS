#
# Until 19 September 2026 the gate had no baseline file. It compared each run to
# the PREVIOUS run recorded in memory/suite_runs.jsonl, which means the baseline
# was written by the run it judged. A failure was "new" exactly once; from the
# next run on it was known, forever, with nobody asked.
#
# Measured over the 58 recorded runs: 57 are VALID and TWENTY of them admitted
# node ids the previous run did not - +19 on 09-03, +23 on 09-06, +30 on 09-08,
# +18 on 09-14, +5 on 09-18. That is not a baseline, it is a ratchet.
#
# FORMAT: one pytest node id per line. Everything after '#' is the triage bucket
# and the reason. Blank lines and full-line comments are ignored.
#
# A LINE HERE IS A DEBT, NOT A DISPENSATION. Adding one is a human decision made
# in a commit; no run may write to this file. If a listed test goes green the
# gate says so and asks for the line to be removed, and if an id here no longer
# exists the gate says that too - a baseline that silently keeps dead entries is
# how 95 failures became invisible.
#
# Seeded from claude/reports/TEST_TRIAGE_2026-09-19.md, which has the full
# evidence for every bucket below.
