# PC4 — EXTRAPOLATION: a result the model has never seen, from a rule it could have induced
### 6 September 2026. Everything below the fold was written BEFORE any model was trained.

## The question

Not "can it fit the corpus" — PC3 answered that. This asks whether a rule induced
from in-range examples produces a **correct answer outside the range of every target
it was ever shown**. Interpolation and extrapolation look identical on a held-out
set drawn from the same range; they separate only here.

## Symbols, not digits

Pretraining already knows arithmetic, so digits would test recall, not induction.
Every number and both operators are replaced by invented tokens, fixed seed 20260906.
**The mapping is printed in the results section**, generated by the harness rather
than chosen by hand.

## A DEVIATION FROM THE SPEC, and why — decided before running

The spec sets the vocabulary at 0..12 and lists eight out-of-range cases. Two of
them cannot be answered in that vocabulary:

```
10+2 = 12   ok        8+3 = 11   ok        9+2  = 11   ok
 9+4 = 13   NO TOKEN  7+5 = 12   ok        6+6  = 12   ok
10+5 = 15   NO TOKEN 10+1 = 11   ok
```

A model with a perfect rule could not emit 13 or 15, because no symbol for them
exists. Scoring those two as failures would measure the vocabulary, not the model.

**Resolution: the vocabulary is 0..15 (16 tokens).** Targets 11..15 exist and are
NEVER a training target, which is exactly the property the spec asked for — the
range is simply wide enough for the test set it specifies. All eight cases are kept.
Dropping the two would have been the alternative; it discards 25% of the test for a
reason that has nothing to do with the hypothesis.

## The data

- **Train**: every `a+b` and `a-b` with a,b in 0..10 whose RESULT lies in 0..10.
  So 11 and above never appear as a target.
- **Test, out-of-range**: the eight cases above, results 11–15.
- **Test, in-range held-out**: 30 cases withheld from training. This is the control
  that a rule was learned at all. **Below 95% here the run is UNRESOLVABLE** — there
  is nothing to extrapolate from, and the out-of-range number means nothing.
- **Memorisation control**: same architecture, same inputs, SHUFFLED targets. Must
  land at ~0% on held-out. If it does not, the split leaks and both arms are void.

## Pre-registered predictions — Claude, on record

**Part A, tiny transformer (2 layers, d=64, ~200k params, 5 seeds, CPU):**
- in-range held-out **≥ 95% on 5/5 seeds**
- out-of-range exact **0–10%**
- most wrong answers will be **10 — the clamp**, not garbage: a model that has never
  emitted a token above 10 as a target has no gradient pushing it there.
- **P(any seed ≥ 50% out-of-range) = 0.10**

**Part B, 3B + LoRA (r=8, q/k/v/o, 3 epochs, ~15 min GPU):**
- in-range held-out **≥ 95%**
- out-of-range **10–40%** — a pretrained model carries ordinal structure that
  invented symbols can partially inherit through tokenisation and position.
- **P(≥ 50%) = 0.25**

**What each outcome would mean, fixed now so it cannot be reframed later:**

- If Part B beats 50% with a 95% CI above chance — **the first evidence on this
  machine of a rule applied beyond its data**, and it goes on the board under (1).
- If it clamps at 10 — the model interpolates, and T8's extrapolation test in the
  sandbox must be designed with that ceiling in mind rather than assuming it away.
- If in-range is below 95% — UNRESOLVABLE, and no claim of either kind is made.

## Scheduling

Part A runs now, on CPU, in minutes. **Part B never runs before A3 finishes** — it
waits for A3's eval (~20:50) or, if A3 runs late, for after tomorrow's cycle (~05:30).
A 15-minute job does not get to jeopardise a 7-hour one.
