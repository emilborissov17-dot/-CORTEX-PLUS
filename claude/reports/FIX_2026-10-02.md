and `.claude/`, parsed with Python's `ast`: a file is listed when it imports `requests`,
`urllib.request`, `httpx`, `aiohttp`, `playwright`, `yt_dlp`, `ddgs`, `duckduckgo_search`,
`feedparser` or `youtube_transcript_api`. **100 files** (the bridge's count was 51; the difference is
that this scan includes `experiments/`, `data_providers/`, `agents/` and the root scripts).
"What it reaches" comes from the URLs named in the file and the calls it makes. "Who calls or
launches it" lists Python files that import or name it by path, launchers (.bat/.ps1/.vbs), the
nightly cycle's steps and the scheduled tasks of STOP_2026-10-02.md; a name in a docstring is
also counted here, so this column OVER-reports. It is not the deletion proof — Part 2 gives that
proof per file with `tools/ask.py callers` and a grep.

**N** reader of a numeric machine interface (and two readers that open a page to verify a quote)
→ reroute through the OpenClaw door (Part 3); **M** model call → stays; **O** outbound channel →
stays; **X** probe / one-off / dead → a proposal each, deleted only with the two proofs.
